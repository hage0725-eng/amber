# paiho-workflow — 共用規則庫＋回歸守門

一句話：規則只寫一次（`core/rules.yaml`），任何修改都要先通過 `tools/gate.py` 的自動對帳才能提交。

## 安裝（Windows）
1. 把整個資料夾放到 `Google 雲端硬碟\Paiho\paiho-workflow`（或任一固定位置）
2. 在資料夾空白處右鍵 →「在終端機開啟」
3. 執行 `powershell -ExecutionPolicy Bypass -File install.ps1`
4. 看到「==> 安裝完成」後執行 `claude`，輸入 `/gate`

gate 沒全綠，安裝會自動中止，不會留下提交。

## 日常用法（在 Claude Code 裡）
| 指令 | 做什麼 |
|---|---|
| `/daily <進度表路徑>` | 跑 daily-progress-review，並用規則庫重判一次，抓 skill 漂移 |
| `/ruling <裁示內容>` | 登錄新裁示 → 改 rules.yaml → 跑 gate → 標「已落地」 |
| `/gate` | 跑回歸守門並解讀 |

## 三道防線
1. Claude 改到規則或程式 → hook 自動跑 gate，紅燈 Claude 必須先修
2. `git commit` → pre-commit 再跑一次，紅燈擋下
3. 黃金樣本禁止 Claude 修改；核定門檻、rules.yaml、產生新樣本都要妳按同意
